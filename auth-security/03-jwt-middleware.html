3a

A typed claims struct, signed at login

Embed jwt.RegisteredClaims for the standard fields and add only what you need.

internal/auth/token.go
type Claims struct {
    Role string `json:"role"`
    jwt.RegisteredClaims  // sub, iat, exp, jti…
}

func IssueAccess(userID, role string,
    ttl time.Duration) (string, error) {
    now := time.Now()
    c := Claims{
        Role: role,
        RegisteredClaims: jwt.RegisteredClaims{
            Subject:   userID,
            IssuedAt:  jwt.NewNumericDate(now),
            ExpiresAt: jwt.NewNumericDate(now.Add(ttl)),
        },
    }
    t := jwt.NewWithClaims(jwt.SigningMethodHS256, c)
    return t.SignedString(secret)
}
→Typed struct over MapClaims — no claims["sub"].(string) assertions later.
→Called once, right after CheckPassword succeeds — typically with 15*time.Minute.
→secret is loaded from the environment at startup (session 10).

3b

One middleware guards every route

Five real requests hit GET /me. Watch which check stops each one.

internal/auth/middleware.go
func RequireAuth(next http.Handler) http.Handler {
    fn := func(w http.ResponseWriter, r *http.Request) {
        h := r.Header.Get("Authorization")
        raw, ok := strings.CutPrefix(h, "Bearer ")
        if !ok {
            http.Error(w, "missing token", 401)
            return
        }
        c := &Claims{}
        _, err := jwt.ParseWithClaims(raw, c, keyFn,
            jwt.WithValidMethods([]string{"HS256"}))
        if err != nil {
            http.Error(w, "invalid token", 401)
            return
        }
        ctx := context.WithValue(r.Context(), ctxKey{}, c)
        next.ServeHTTP(w, r.WithContext(ctx))
    }
    return http.HandlerFunc(fn)
}

// wiring
mux.Handle("GET /me", RequireAuth(http.HandlerFunc(me)))

→Wrap only protected routes — /login and /register stay public.

3c

Handlers read claims, never tokens

The middleware verified once; handlers just ask the context who is calling.

internal/auth/context.go
type ctxKey struct{} // unexported: no collisions

func ClaimsFrom(ctx context.Context) *Claims {
    c, _ := ctx.Value(ctxKey{}).(*Claims)
    return c
}

func me(w http.ResponseWriter, r *http.Request) {
    c := ClaimsFrom(r.Context())
    fmt.Fprintf(w, "hello user %s (%s)", c.Subject, c.Role)
}
→Unexported key type — no other package can overwrite or read your value by accident.
→One helper, ClaimsFrom, is the only way in — easy to fake in tests.
✓Sessions 05–06 read c.Role and c.Subject from here to authorize.
Mistake

Trusting a user id from the request body or query string. The only trustworthy identity is c.Subject from a verified token.
