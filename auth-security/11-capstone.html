11c

The wiring and the one place errors are decided

Handlers return errors. httpx.Handle turns safe ones into their status and everything else into a bare 500.

internal/app/routes.go
func Routes(h *user.Handler, origins []string) http.Handler {
    mux := http.NewServeMux()
    H := httpx.Handle
    authn := func(next http.Handler) http.Handler {
        return auth.RequireAuth(h.Tokens, h.Refresh, next)
    }
    owner := func(next http.Handler) http.Handler {
        return authn(authz.OwnerOrAdmin(authz.PathOwner("id"), next))
    }
    admin := func(p authz.Perm, next http.Handler) http.Handler {
        return authn(authz.RequirePerm(p, next))
    }
    // one bucket per route: a shared one locks out normal users
    loginLim := httpx.NewIPLimiter(time.Minute/5, 5).Limit     // 5/min
    signupLim := httpx.NewIPLimiter(time.Minute/5, 5).Limit    // 5/min
    refreshLim := httpx.NewIPLimiter(time.Minute/30, 30).Limit // 30/min

    // public, rate limited
    mux.Handle("POST /auth/register", signupLim(H(h.Register)))
    mux.Handle("POST /auth/login", loginLim(H(h.Login)))
    mux.Handle("POST /auth/refresh", refreshLim(H(h.RefreshToken)))

    // authenticated
    mux.Handle("POST /auth/logout", authn(H(h.Logout)))
    mux.Handle("GET /users/me", authn(H(h.Me)))

    // owner or admin
    mux.Handle("GET /users/{id}", owner(H(h.Get)))
    mux.Handle("PATCH /users/{id}", owner(H(h.Patch)))

    // admin only
    mux.Handle("GET /admin/users", admin(authz.ListUsers, H(h.List)))
    mux.Handle("PATCH /admin/users/{id}/role", admin(authz.SetRole, H(h.SetRole)))

    return httpx.Recover(httpx.SecureHeaders(httpx.CORS(origins, mux)))
}
internal/httpx/errors.go
// Error is an error that is safe to show the client.
type Error struct {
    Status int
    Msg    string
}

// Handle is the one place errors become responses.
func Handle(h HandlerFunc) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        err := h(w, r)
        if err == nil {
            return
        }
        var e *Error
        if !errors.As(err, &e) {
            slog.Error("internal", "path", r.URL.Path, "err", err)
            e = &Error{500, "internal error"}
        }
        JSON(w, e.Status, map[string]string{"error": e.Msg})
    })
}

// Recover turns a panic into a clean 500; the stack goes to the log only.
func Recover(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        defer func() {
            if v := recover(); v != nil {
                slog.Error("panic", "path", r.URL.Path, "value", v,
                    "stack", string(debug.Stack()))
                JSON(w, 500, map[string]string{"error": "internal error"})
            }
        }()
        next.ServeHTTP(w, r)
    })
}
→Safe errors are typed (*httpx.Error): 400, 401, 404, 409, 413, 422, 429. Anything else — a DB error, a bug — becomes internal error.
→The detail goes to the log, keyed by path; the client never sees a hostname, SQL or stack.
→Recover is outermost, so a panic anywhere — even in a middleware — still gets a clean reply.
Found in the first run

The first version used one limiter for register, login and refresh. A normal journey — sign up, log in, refresh — hit 429 on its 6th request. Each route now has its own bucket, and refresh gets 30/min.

11e

The brief, feature by feature

Everything the capstone had to include — and the file it lives in.

Registration & login

  • bcrypt cost 12, dummy hash for unknown emails
  • 15-min access JWT with jti
  • 7-day refresh, rotated, reuse-detected
auth/password.go · token.go · refresh.go

Auth middleware

  • Bearer parse, HS256 pinned
  • denylist check, fails closed
  • claims in context
auth/middleware.go

RBAC & ownership

  • permission map, default deny
  • OwnerOrAdmin → 404 for others
  • role never taken from input
authz/authz.go · user/handler.go

Hardening

  • per-route rate limits
  • CORS allowlist, 5 security headers
  • 1 MB bodies, strict JSON, validation
  • HttpOnly · Secure · SameSite cookie
  • server timeouts, config refuses bad boot
httpx/security.go · decode.go · cmd/api

Centralised errors

  • one Handle maps errors to status
  • unknown errors → bare 500
  • panics recovered, stack to log only
httpx/errors.go

Recap

The whole track in four lines

1Prove identity: bcrypt, short JWTs, rotated refresh tokens in HttpOnly cookies.
2Decide access: permissions by role, ownership per row, attributes where needed — default deny.
3Distrust input: placeholders, size limits, strict JSON, rate limits, CORS, headers, TLS.
4Leak nothing: secrets from env, json:"-", redacted logs, one error handler, least-privilege roles.
