Ownership & IDOR

A valid token proves who you are — not that this row is yours.

6a

Change one number in the URL

Insecure Direct Object Reference: the server trusts the id in the request. Asha is user 7.

✗Authentication passed every time — Asha's token is genuine. The bug is a missing authorization check.
→OWASP calls this BOLA (Broken Object Level Authorization) — #1 on the API Top 10.
→UUIDs instead of 7, 8, 9 make guessing harder but fix nothing — ids leak in links, logs and emails.

6b

One guard for every owned resource

The middleware only needs one question answered: who owns this? Each route passes a function that answers it.

internal/authz/owner.go
// OwnerFunc returns the user id that owns the target.
type OwnerFunc func(r *http.Request) (string, error)

// PathOwner: the {param} in the URL *is* the owner id.
func PathOwner(param string) OwnerFunc {
    return func(r *http.Request) (string, error) {
        return r.PathValue(param), nil
    }
}

// PostOwner: load the post, return who owns it.
func PostOwner(r *http.Request) (string, error) {
    p, ok := posts[r.PathValue("id")]
    if !ok {
        return "", ErrNotFound
    }
    return p.OwnerID, nil
}

func OwnerOrAdmin(owner OwnerFunc,
    next http.Handler) http.Handler {
    fn := func(w http.ResponseWriter, r *http.Request) {
        c := auth.ClaimsFrom(r.Context())
        id, err := owner(r)
        if err != nil {
            http.Error(w, "not found", 404)
            return
        }
        if c.Subject != id && c.Role != "admin" {
            http.Error(w, "not found", 404)
            return
        }
        next.ServeHTTP(w, r)
    }
    return http.HandlerFunc(fn)
}

// wiring
mux.Handle("PATCH /users/{id}", guard(PathOwner("id"), patchUser))
mux.Handle("PATCH /posts/{id}", guard(PostOwner, editPost))

→Compare against c.Subject from the verified token — never an id from the body or a header.
→404, not 403, for someone else's resource — don't confirm that user 8 exists.
→Nested resources (a post, an order) load the owner from the database — the URL alone can't tell you.
→For list endpoints, filter in the query: WHERE owner_id = $1.
HANDS-ON · TOPIC 2

Edit own profile — or any, as Admin

  • PATCH /users/{id} wrapped in RequireAuth(OwnerOrAdmin(PathOwner("id"), …)).
  • A user can change only their own name; an admin can change anyone's.
  • Reuse the same guard for PATCH /posts/{id} with a PostOwner loader.
  • Tests: own → 200, other → 404, admin → 200, no token → 401.

Recap

Session 06 in four lines

1IDOR / BOLA: a valid user reading or writing a row that isn't theirs.
2Every object access checks owner == claims.Subject (or admin).
3One generic guard + a small OwnerFunc per resource type.
4Answer 404 to non-owners; UUIDs are not a substitute for the check.
